Examples

Every distinct visual identity currently in use across this site and its six sister projects, side by side, under abstract codenames.

This gallery exists so the differences are visible in one place before any of them is changed. Each card links to a dedicated page that renders the style with representative components and lists the exact tokens (palette, typography, radii, spacing, signature motifs) that make it look that way. Codenames are deliberately abstract — they're not derived from the projects that use them — so the conversation can stay about the style rather than the product.
