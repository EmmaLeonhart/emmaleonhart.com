03 — What "synoptic" means here

Each site keeps its own content and structure (Sutra's nav is good, your main site's is good) but is rebuilt so the chrome is literally the same parts: this bar, this widget, this search, this toggle, these buttons, this palette. Send the reference attachments and I'll tune this page to match exactly what you're picturing, then roll it site by site.
