I work on the geometry side of AI — geometric tensor languages, vector retrieval, and the knowledge graphs that ground them. The output is a programming language, a database, and interactive tutorials that show how the math actually works.

About

My main thesis is that what looks like reasoning in modern language models is mostly continuous geometric operations on embedding spaces — and that we get more debuggable, more controllable systems when we treat that fact as load-bearing instead of papering over it with simulated symbolic logic.

That conviction shows up in three places. Sutra is the language I’m building to express programs as straight-line tensor arithmetic with no control flow at all. SutraDB is the bundled retrieval layer that grounds those programs in real data. The interactive tutorials show what is actually happening inside neural networks — you can’t hand-wave a visualization that you have to drag with your mouse.

Adjacent work: knowledge graph pipelines for Wikidata and Pramana, lexicographic infrastructure on the Aelaki Wikibase, and context-management libraries for AI agents.

Flagship

📜 Sutra In development
A geometric tensor programming language.

Every value is a tensor. Every operation is tensor arithmetic in a geometric space. There is no print, no if, no while — branches are continuous weighted blends and loops are geometric rotations. Programs compile to straight-line tensor operations, which makes them GPU-native and end-to-end differentiable by construction.

I’m building the reference compiler (PyTorch backend), the IntelliJ and VS Code plugins, the language specification, and the interactive demos — plus SutraDB, the bundled vector database that lives inside the same ecosystem. The name comes from the Sanskrit sūtra, the word used for Pān&dotbelow;ini’s grammar of Sanskrit, the earliest known formal grammar of any language.

Research Areas

Geometric Tensor Languages Languages

Designing Sutra: a programming language with no control flow, where conditional branches are weighted geometric blends and iteration is rotation in tensor space. Goal: programs that are GPU-native and differentiable by construction.

Sutra compiler & spec IDE tooling (IntelliJ, VS Code)
Vector Retrieval & Graph Databases SutraDB

SutraDB unifies HNSW vector indexing with RDF graph traversal. The eight theory pages explain the design: subgraph SIMD indexes, SPARQL exit conditions, traversal optimization, and where hybrid databases beat pure-vector or pure-graph stores.

HNSW in RDF Subgraph SIMD indexing Hybrid query planning
Knowledge Graphs & Lexicography Wikidata · Pramana

Wikidata pipelines for the Shinto knowledge graph (Engishiki shrines, Shikinai Ronsha disambiguation), lexeme infrastructure on the Aelaki Wikibase, and Pramana — a structured-citation system for grounding language model outputs in primary sources.
