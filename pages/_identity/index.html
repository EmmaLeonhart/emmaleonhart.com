Canonical visual identity

One identity.

The system every page on this site and every sister project converges on: the Lacquer surface, the Pewter button, and a dark/light toggle that lives in the top-right corner of every screen.

This page is the reference, not decoration. It renders the identity and carries the exact tokens and the copy-paste block below. The site is intentionally framework-free — there is no shared bundle; each page copies this block so it stays self-contained and debuggable on its own.

What changed from plain Lacquer
Buttons are now Pewter's
The primary button is a solid --accent fill with a --on-accent label — prominent and unmissable — instead of Lacquer's original hairline outline. Secondary is a filled card-surface button with a border that turns accent on hover. Both lift 1 px on hover; neither animates continuously.
A toggle in the top-right of every page
Fixed at top:18px; right:18px. Sun icon in dark mode (click → light), moon in light mode (click → dark). The choice is saved to localStorage. Dark is the default on first visit, regardless of the operating system setting. Try it — the toggle is in the corner now.
Everything else is Lacquer, unchanged
Near-black blue-tinted background, periwinkle accent, the Inter / Instrument Serif / JetBrains Mono trio, the drifting aurora, the eyebrow pill with its pulsing dot, gradient-text headlines. Light mode keeps the same character with a darkened periwinkle that holds contrast on a near-white surface.

  color:      var(--on-accent);  // flips per theme
}
.btn-secondary {
  background: var(--bg-card);
  border:     1px solid var(--border);
}

Typography
Body / UI Inter 400–800 · display italics Instrument Serif · mono JetBrains Mono. Body letter-spacing: -0.005em, antialiased.
Buttons
padding: 12px 26px, border-radius: 8px, weight 600. Primary = solid --accent + --on-accent label. Secondary = --bg-card + --border. Hover: brighten + translateY(-1px).
Toggle widget
40×40 px circle, fixed top:18px right:18px, z-index:100. Pre-paint inline script sets data-theme from localStorage (dark default) so there is no flash. One click handler swaps + persists.
Carried from Lacquer
Aurora (three blurred radial blobs, 22/26/30 s drifts, screen-blended; opacity rises in light mode), eyebrow pill + pulsing dot, gradient headline, 760–780 px column. All respect prefers-reduced-motion.

The drop-in block

Paste this into <head> (pre-paint script + token block), the button in the body, and the handler before </body>. Self-contained — no external file.

<!-- 1. in <head>, BEFORE any stylesheet -->
<script>(function(){try{var t=localStorage.getItem('theme');
if(t!=='light'&&t!=='dark')t='dark';
document.documentElement.setAttribute('data-theme',t);}
catch(e){document.documentElement.setAttribute('data-theme','dark');}})();</script>

// 2. the :root + html[data-theme="light"] token blocks above
//    (the canonical values; same names, values flip per theme)

<!-- 3. the .theme-toggle button markup + .theme-toggle CSS -->

<!-- 4. before </body> -->
<script>(function(){var b=document.getElementById('theme-toggle');
if(!b)return;b.addEventListener('click',function(){
var c=document.documentElement.getAttribute('data-theme')==='light'?'light':'dark';
var n=c==='light'?'dark':'light';
document.documentElement.setAttribute('data-theme',n);
try{localStorage.setItem('theme',n);}catch(e){}});})();</script>
